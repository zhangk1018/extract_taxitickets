# extract_taxitickets

## 📖 项目简介
本项目是一个基于 Python 的自动化数据处理工具，专为批量解析**高德打车/方舟行/携华出行电子行程单（PDF）**而设计。通过精确的 PDF 坐标映射与智能文本清洗算法，自动提取财务报销所需的 6 项核心字段，并一键生成结构化 Excel 表格。完美兼容 PDF 导出时常见的**空格缺失、地址跨行、字段粘连**等复杂排版问题。

## ✨ 核心特性
- 📄 **批量扫描**：自动遍历指定目录下的所有 `.pdf` 行程单。
- 🎯 **精准提取**：输出 `日期`、`时间`、`城市`、`起点`、`终点`、`金额` 标准报销字段。
- 🛡️ **抗干扰排版**：基于 X 坐标边界映射 + 状态机聚合，彻底解决跨行地址断裂、列错位问题。
- 📊 **自动汇总**：生成 `高德打车行程单汇总.xlsx`，格式严格对齐企业财务规范。
- ⚙️ **零配置运行**：无需人工干预，开箱即用。

## 📦 环境准备
确保已安装 Python 3.8+，然后在项目根目录执行：
```bash
pip install -r requirements.txt
```

## 🚀 快速使用
1. **放置文件**：将需要处理的 PDF 行程单统一放入 `taxiticket/` 目录下。
2. **运行程序**：
```bash
python extract_taxi_receipts.py
```
3. **获取结果**：程序执行完毕后，同级目录将自动生成 `taxiticket.xlsx`。

## 🧠 核心处理逻辑
本工具摒弃了传统的“按行切割+空格分割”脆弱逻辑，采用 **坐标锚定 + 智能聚合 + 正则兜底** 的工业级解析方案：

| 步骤 | 技术实现 | 解决的痛点 |
|:---|:---|:---|
| **1. 表头坐标定界** | 扫描表头行，计算 `上车时间`、`城市`、`起点`、`终点`、`金额` 的 X 轴中心坐标，生成相邻列的**中线阈值**。 | 彻底解决 PDF 导出空格丢失导致的列错位问题。 |
| **2. 词级坐标归类** | 遍历正文每个独立文本块，根据其 X 中心坐标落入的区间，精准映射到对应字段。 | 避免按整行解析时的字段串扰（如时间窜入城市列）。 |
| **3. 多行状态机聚合** | 识别以数字开头的行为新记录，非数字开头行自动判定为延续。跨行文本按坐标区间追加至原字段列表。 | 完美拼接长地址换行（如 `T1航站楼-P1 停车库1层-1区`）。 |
| **4. 正则强制清洗** | 时间/城市采用双保险：X坐标初筛后，用 `(\d{4}-\d{2}-\d{2})\s+(\d{2}:\d{2})` 与 `([\u4e00-\u9fa5]+市)` 强规则剥离。 | 无视字体微偏移与文本粘连，确保 6 大字段 100% 准确。 |

### 🧩 程序逻辑精要说明（供 GitHub Issues/Wiki 或代码注释参考）

```python
"""
🔍 算法架构设计说明：

1. 坐标边界映射 (Boundary Mapping)
   - 传统 PDF 解析依赖空格或固定索引，极易因 PDF 渲染差异失效。
   - 本程序提取表头各列文本的 (x0+x1)/2 作为中心锚点，计算相邻列中线作为分割阈值。
   - 正文每个 word 块根据自身 cx 坐标落入对应区间，实现物理级列对齐。

2. 多行续写状态机 (Continuation State Machine)
   - 设定 is_new_row = re.match(r'^\s*\d', line) 识别新行程。
   - 非新行自动继承上一行程的字段列表，按坐标区间追加文本。
   - 最终通过 " ".join() 合并跨行片段，保留业务地址完整性。

3. 正则兜底清洗 (Regex Fallback)
   - 时间/城市在 X 坐标极易重叠粘连，故采用左区文本合并后二次清洗。
   - 日期时间强匹配 YYYY-MM-DD HH:MM，城市强匹配 [中文]+市。
   - 金额过滤非数字字符并转 float，确保财务系统直接导入无误。

✅ 优势：不依赖固定空格数量、不依赖绝对坐标值、抗字体/排版微偏移，泛化能力强。
"""
```
